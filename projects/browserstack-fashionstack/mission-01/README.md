# Mission 01: The AI Test Architect

## Manual Test Suite Evidence

This folder preserves the FashionStack manual test suite created and refined in BrowserStack Test Management for Mission 01 of the 2026 BrowserStack AI Hackathon E-Commerce Track.

### Full 16-case spreadsheet

- [`M01_FashionStack_Manual_Test_Suite_16_Cases.csv`](./M01_FashionStack_Manual_Test_Suite_16_Cases.csv)

The spreadsheet contains all **16 FashionStack test cases**, organized as four cases for each user story:

- **US-01 Homepage Hero Carousel:** 4 cases
- **US-02 Men's Category Inventory:** 4 cases
- **US-03 Persistent Cart Counter:** 4 cases
- **US-04 Authentication:** 4 cases

The suite includes Happy Path, Negative, and Edge Case coverage and preserves the BrowserStack Test Management IDs and direct case URLs, including TC-300 and TC-301 used later in Mission 05 result mapping.
